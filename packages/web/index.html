Machines

    On each machine: install the Scranton plugin, then run paseo pair (or open Settings → Pair a device in Paseo) and paste the link here.

    A pairing link gives full control of that Paseo daemon. It stays in this browser's storage and is only used to open an end-to-end encrypted connection through Paseo's relay. It is never sent to this website. Only add links on a browser you trust, and remove them here to forget them.
